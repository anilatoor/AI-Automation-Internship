Title       : docs: fix broken template links with unescaped parentheses

Summary of the change:
Nine "Link to Template" entries in README.md pointed to filenames
containing literal, unescaped parentheses (e.g. "AI (55 supported
languages).json"). Because Markdown link syntax [text](path) treats the
first unmatched ")" as the end of the link, these links were silently
truncated and returned a 404 when clicked. This PR percent-encodes the
parentheses (%28 / %29) in the affected paths, matching the convention
already used for every other filename with special characters elsewhere
in the same table. It also fixes the "Glasp Highlights Auto Export" link,
which used a hardcoded absolute URL pointing back at the upstream repo
instead of a relative path — meaning the link broke for anyone browsing
the README from a fork rather than the original repository.

Testing performed:

- Confirmed the relative-path fix renders correctly both on the
  upstream repo and on a personal fork, where the previous hardcoded
  link would have 404'd.
- No workflow JSON files were modified — documentation only.
