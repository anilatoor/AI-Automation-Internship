# AI Automation Internship

## No-Code & Low-Code Systems Engineering

This repository documents my learning journey, practical tasks, projects, and technical contributions completed during my **AI Automation No-Code / Low-Code System Engineering Internship at MATalogics**.

The internship focuses on building practical AI-powered automation systems using **No-Code and Low-Code technologies**, APIs, workflow automation platforms, AI agents, integrations, and supporting software engineering practices.
